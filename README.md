#LANGGRAPH MATH AGENT.

1.Built an agentic AI workflow using LangGraph and Claude Haiku 4.5 (via AWS Bedrock AgentCore) capable of performing structured mathematical operations through tool-calling and multi-step reasoning.
2.Containerized the agent using Docker and deployed to production via AWS ECR (image registry) and ECS (container orchestration).
3.Implemented modular tool nodes in LangGraph to handle arithmetic, expression parsing, and stateful agent memory across multi-turn interactions.
